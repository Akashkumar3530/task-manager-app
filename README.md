# Task Manager App

A responsive Task Manager web application built with React and Vite that supports full task CRUD operations, priority levels (**High**, **Medium**, **Low**), filtering, and persistent storage via `localStorage`.

## Features

- **Create, Read, Update, and Delete (CRUD) Tasks:** Add new tasks, view/filter existing tasks, edit task details or completion status, and remove tasks.
- **Priority Levels:** Assign and distinguish tasks by **High**, **Medium**, and **Low** priority.
- **Data Persistence:** Automatically saves and restores tasks using browser `localStorage` so your list stays intact across page refreshes.
- **Responsive Design:** Adapts cleanly across mobile, tablet, and desktop screen sizes.

## Tech Stack

- **Frontend:** React, Vite
- **Styling:** CSS
- **Persistence:** Browser `localStorage`
